01魅力

手元にあるから、
できること。

生成AIを使ったことがあるなら、次は「どこで動かすか」を選んでみる番です。ローカルLLMは、そのひとつの選択肢です。

TRYA

手元で試す楽しさ

思いついたらその場で動かし、設定を変えて、もう一度。手元にあるからこそ、仕組みに触れながら遊ぶように確かめられます。

CHOOSEB

用途に合わせて、モデルを選ぶ自由

モデルはひとつではありません。やりたいことと手元の機器に合わせて、自分で選び、入れ替えながら使えます。

DESIGNC

データの扱いを、自分で設計できる

どの資料を読ませ、どこに置き、何とつなぐか。データの流れを自分で決められます。

設定や外部連携によっては通信が発生します。詳しくは「注意」へ。

  1. 01

    用途を決める

  3. 03

    ライセンスや利用条件を読んでから選びます。すべてのモデルが無料・商用利用可能とは限りません。

    小さく試す

    まずは短い入力で、ひとつの用途から。動きを確かめながら、少しずつ広げていきます。

04注意

始める前に、
知っておきたいこと。

ローカルLLMは万能ではありません。期待とのずれを減らすために、先に3つだけ。

  1. NOTE 01

    速度と必要メモリは、一定ではありません。

    どちらもモデル・機器・設定によって変わります。このページに数値を載せていないのは、そのためです。

  2. NOTE 02

    すべてのモデルが、無料・商用利用可能とは限りません。

    モデルごとに利用条件があります。使い始める前に、必ず自分で確認してください。

  3. NOTE 03

    ローカル実行だけで、完全な秘密保持が保証されるわけではありません。

    外部連携や設定によっては通信が発生します。データの扱いは「自動で守られる」ものではなく、自分で設計して確かめるものです。
