01 / WHY LOCAL

手元で動かす、3つの魅力。

クラウドのAIサービスと比べて「どちらが上」という話ではありません。自分の手で動かすからこそ得られる体験があります。

01

手元で試す楽しさ

思いついたら、自分の環境ですぐ実験。プロンプトや設定を少し変えて、返ってくる答えの違いを観察する——仕組みに触れながら遊べる面白さがあります。

試し方を見る →
02

モデルを選ぶ自由

大きさ、得意な分野、利用条件。性格の違うモデルの中から、用途と機器に合うものを選び、入れ替えて比べられます。正解はひとつではありません。

選び方のポイント →
03

データの扱いを設計できる

どのファイルを読ませるか、何を外部とつなぐか。データがどこを通るかを、自分で決めて組み立てられます。

※ ローカル実行だけで完全な秘密保持が自動的に保証されるわけではありません。 データの流れを見る →

02 / DATA FLOW

データの通り道を、自分で決める。

ローカルLLMでは、入力からモデル、出力までを手元の機器で処理できます。ただし外部連携や設定しだいで通信は発生します。スイッチで違いを確かめてください。

YOUR PC / 手元の計算機
入力・資料質問、メモ、コード
モデル自分で選んで実行
出力下書き、整理結果
外部サービス検索・拡張機能・同期など

外部連携を使わない構成なら、入力・モデル・出力の流れをこの機器の中にとどめるよう設計できます。

03 / USE CASES

たとえば、こんな使い方。

毎日の作業の「最初のたたき台」に。手元で動かすからこそ、気軽に何度でも試せます。

  • USE 01

    文章の下書き

    メール、企画メモ、ブログの構成案など。ゼロから書く前の「たたき台」を作り、自分の言葉で仕上げていきます。

    この箇条書きを、ていねいなお知らせ文にして
  • USE 02

    コードの相談

    エラーの読み解き、関数の説明、書き方の別案。手元のコードを見せながら、壁打ち相手として使えます。

    この関数が何をしているか、順番に説明して
  • USE 03

    手元資料の整理

    議事メモや読書ノートを要点に分けたり、見出しをつけたり。散らかった情報に、最初の秩序を与えます。

    このメモを、決定事項と宿題に分けて

うまくいくかどうか、どれくらい正確かは用途とモデルに依存します。出力はそのまま使わず、内容を確認してから活用しましょう。

04 / GET STARTED

導入は、4つのステップで。

いきなり大きく始める必要はありません。順番に確認して、小さく動かすところから。

0 / 4自分用チェック（この画面の中だけで使えます）

  1. 1

    ステップ1：用途を決める

    何に使いたいかで、向いているモデルや必要な機器が変わります。まずは目的をひとつに絞りましょう。

    • 文章の下書き？ コードの相談？ 資料の整理？
    • 日本語でのやりとりが中心か
    • どんなデータを扱うか（個人情報・社外秘を含むか）
  2. 2

    ステップ2：機器と必要メモリを確認する

    ローカルLLMは手元の機器の力で動きます。モデルごとに必要なメモリ量が異なるため、先に自分の環境を把握しておきます。

    • PCのメモリ（RAM）と、あればGPUのメモリ
    • モデルを置くためのストレージの空き容量
    • 必要量の目安は、モデル配布元の情報で確認する
  3. 3

    ステップ3：利用条件を読んでモデルを選ぶ

    モデルにはそれぞれライセンスや利用条件があります。すべてが無料・商用利用可能とは限りません。

    • 個人利用・商用利用それぞれの可否
    • 再配布や改変に関する条件
    • 用途（ステップ1）と機器（ステップ2）に合う大きさか
  4. 4

    ステップ4：小さく試す

    小さめのモデル、短い入力、重要ではないデータから。自分の用途で速度や出力の質感を確かめ、少しずつ広げていきます。

    • まずは短い質問や要約で動作を確認
    • 外部連携の設定がどうなっているかも確認
    • 物足りなければ、モデルや設定を入れ替えて比べる

05 / BEFORE YOU START

始める前に、知っておきたいこと。

かっこよさの裏側にある、正直なポイントです。

NOTE 01

速度と必要メモリは「条件しだい」

応答の速さや必要なメモリは、モデル・機器・設定によって大きく変わります。同じモデルでも環境が違えば体感は別物です。

NOTE 02

無料・商用可とは限らない

モデルごとに利用条件が定められています。特に仕事で使う場合は、商用利用の可否や条件を必ず確認してください。

NOTE 03

ローカル＝自動的に秘密保持、ではない

外部連携や設定によっては通信が発生します。どこに何が送られうるかを確認し、データの扱いを自分で設計することが大切です。

このページは特定の製品・サービスの販売を目的としたものではありません。性能の数値、順位、導入実績などは掲載していません。
